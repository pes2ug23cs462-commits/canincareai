# Deploying CanineCare AI

The app reads all secrets from environment variables, so no keys are committed.
You need two API keys ready: `GEMINI_API_KEY` and `GEOAPIFY_API_KEY`.

## Option A — Render (deploys straight from this GitHub repo) — easiest

1. Go to https://render.com and sign in with GitHub.
2. New → **Web Service** → pick this repo (`canincareai`).
3. Render detects the `Dockerfile` automatically (runtime: Docker).
4. Plan: **Free**.
5. Add environment variables:
   - `GEMINI_API_KEY` = your Gemini key
   - `GEOAPIFY_API_KEY` = your Geoapify key
   - `DEBUG` = `False`
   - (`SECRET_KEY` is auto-generated by `render.yaml`)
6. Create Web Service. First build takes a few minutes (PyTorch is large).
7. Open the given `*.onrender.com` URL.

> Note: the free plan has 512 MB RAM and sleeps after 15 min of inactivity
> (first request after sleep is slow). The SQLite database resets on each
> redeploy, so accounts are not permanent on the free plan.

## Option B — Hugging Face Spaces (more RAM, most reliable)

1. Go to https://huggingface.co and create an account.
2. New → **Space** → SDK: **Docker** (blank template).
3. Upload / push all files from this repo into the Space (including the `Dockerfile`).
4. In the Space, add a `README.md` with this frontmatter at the very top:
   ```
   ---
   title: CanineCare AI
   sdk: docker
   app_port: 7860
   ---
   ```
5. Space → Settings → **Variables and secrets** → add:
   - `GEMINI_API_KEY`, `GEOAPIFY_API_KEY` (as secrets)
   - `DEBUG` = `False`
   - `SECRET_KEY` = any long random string
6. The Space builds and runs automatically.

## Local run
```bash
cd webapp
pip install -r requirements.txt
# create webapp/.env with GEMINI_API_KEY and GEOAPIFY_API_KEY
python manage.py migrate
python manage.py runserver
```
